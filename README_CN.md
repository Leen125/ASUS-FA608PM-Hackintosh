ASUS TUF AMD Hackintosh

面向华硕天选 AMD 笔记本的 OpenCore EFI 与 macOS 兼容性研究项目。

本项目以 ASUS TUF Gaming FA608PM 为首个实际验证样本，记录 EFI 配置、硬件兼容性、已知问题及测试结果，并逐步研究其他 AMD Zen 4 架构的天选笔记本。

English README

项目目标

* 整理并维护经过记录的 OpenCore EFI 配置。
* 记录不同硬件与 macOS 版本的兼容性。
* 提供安装、测试与故障排查文档。
* 研究其他 ASUS TUF AMD 笔记本的兼容性。
* 鼓励社区提交可复现的测试结果。

其他机型

本项目计划逐步研究其他搭载 AMD Zen 4 处理器的 ASUS TUF 笔记本。

不同机型可能具有不同的 ACPI、PCI 设备路径、USB 控制器、无线网卡及显示输出配置。未经实际测试的机型不会标记为已支持。

第三方组件

项目可能使用 OpenCore、第三方 Kext、ACPI 组件及其他独立项目。

所有第三方组件均应遵循各自适用的许可证，并保留必要的版权与来源声明。
