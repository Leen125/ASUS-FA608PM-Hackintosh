## 项目简介

本仓库记录 **ASUS TUF Gaming A16 FA608PM** 的 Hackintosh
研究过程，包括当前测试配置、硬件兼容性、OpenCore
相关说明、已知限制以及可复现的测试结果。

本项目强调如实记录，而不是宣称所有功能均已兼容。**能够启动
macOS，并不代表所有硬件和系统功能都能正常工作。**

## 项目目标与范围

本项目计划：

-   记录测试设备及当前 macOS 配置。
-   跟踪各项硬件功能的正常、异常和未测试状态。
-   让配置变更、问题原因与排查结论尽可能清晰可追溯。
-   在经过验证后补充安装说明与可复现的测试流程。
-   研究第三方显卡驱动，但不夸大其实际能力。
-   未来探索其他 AMD 处理器的 ASUS TUF
    笔记本，但每个具体型号都必须独立测试。

本仓库不是适用于所有机器的通用 EFI。不同硬件修订、BIOS
设置、固件版本和部件替换都可能影响兼容性。

## 已知问题

### 蓝牙

当前记录的 Realtek USB 蓝牙设备（`VID:PID 0489:E122`）在此 macOS
配置下无法正常工作。本项目暂不宣称已有解决方案。若进行后续排查，应记录
USB 设备识别情况、相关日志和每次测试的配置变化。

### 屏幕亮度调节

当前无法正常调节屏幕亮度。问题可能涉及平台专用
ACPI、屏幕面板控制或其他硬件与固件行为。不要在不了解影响且没有备份的情况下，随意添加
ACPI 补丁。

### NVIDIA 显卡

引入第三方驱动不等于 RTX 5060 Laptop GPU
已经获得完整支持。显卡加速、Metal、显示输出、睡眠行为和具体应用的兼容性，都需要分别验证。

### 音频配置

目前音频正常。此前排查时，将旧 EFI 中已经验证可用的音频
`DeviceProperties` 配置迁移到新 EFI 后，音频恢复正常。如果 EFI
更新后音频再次失效，应优先对照已知可用的配置，而不是反复修改无关设置。分享配置文件前，务必移除个人标识信息。

支持和应用兼容性，都必须通过实际测试确认。

记录测试结果时，建议包含：

-   macOS 版本及可获取的系统构建号。
-   实际使用的驱动版本或提交版本。
-   安装方式与启动条件。
-   测试方法、预期结果和实际结果。
-   已移除个人标识信息的相关日志。

在没有可复现的测试证据之前，不要宣称显卡已经实现完整加速或兼容 Metal。

## 开始之前

> \[!WARNING\] 安装 Hackintosh 或修改 EFI
> 可能导致系统无法启动，甚至造成数据丢失。请在了解风险后再操作。

开始之前：

1.  备份重要文件，并准备好恢复方案。
2.  单独保存当前能够正常工作的 EFI。
3.  确认可以进入固件设置，并具备可用的恢复介质。
4.  记录 BIOS、macOS、OpenCore 和 Kext 的准确版本。
5.  阅读所有第三方组件的文档与许可证。
6.  每次只修改一个变量，并记录修改结果。
7.  不要未经检查就直接使用其他笔记本型号的 EFI。

本仓库是研究与测试记录，不保证配置可以直接用于其他设备。

## 安装流程

经过完整验证的安装教程应放在 `docs/INSTALLATION.md`
中。在该文档尚未完成端到端验证之前，以下内容仅为高层次流程，并不代表所有步骤已经在所有设备上验证成功。

1.  **核对硬件。** 确认笔记本的准确型号与硬件修订。
2.  **准备恢复方案。** 备份数据，并保存已知可用的 EFI。
3.  **检查配置。** 了解正在使用的 OpenCore 版本、ACPI
    文件、Kext、驱动和配置项。
4.  **检查第三方要求。** 遵循外部驱动和工具的上游文档与许可证。
5.  **验证配置文件。** 使用与实际 OpenCore
    版本相对应的文档，不要盲目跨版本复制设置。
6.  **谨慎启动并测试。** 记录启动结果，并逐项验证硬件功能。
7.  **记录故障。** 保存经过脱敏的日志，并写明最后一次修改。
8.  **更新兼容性表。**
    只有在目标设备上完成测试后，才将相应功能标记为正常。

除非仓库中确实存在相应文件，否则不要假定本项目包含 macOS 安装器、EFI
压缩包或第三方驱动。

## EFI 与配置说明

OpenCore
配置对硬件和版本较为敏感。应记录每次修改的原因，并确保修改过程可以追溯。

建议逐步补充以下配置区域的说明：

-   `ACPI`：使用的 ACPI 表与补丁。
-   `Booter` 和 `Kernel`：启动行为与内核相关设置。
-   `DeviceProperties`：设备属性，包括已经验证可用的音频配置。
-   `NVRAM`：启动参数与存储变量。
-   `UEFI`：固件驱动和启动设置。
-   `Kernel -> Add`：Kext、版本、依赖和来源。
-   `Misc`：OpenCore 工具、安全设置和启动选择界面行为。

以上是文档整理建议，并不表示仓库中每一项都已完成配置或验证。

**重要：** 不要公开个人的 `SystemSerialNumber`、`MLB`、`SystemUUID`
或其他可识别设备的信息。分享前应检查并脱敏 `config.plist`、日志、截图和
EFI 压缩包。原始配置请自行妥善备份。

## 故障排查

### 通用流程

1.  确认最近一次修改的内容。
2.  使用一致的步骤复现问题。
3.  与最后一个已知可用的配置进行对照。
4.  每次只更改一个变量。
5.  保存日志，并在分享前移除个人标识信息。
6.  如果修改导致问题加重，先恢复备份，再尝试其他方案。

### 修改 EFI 后音频失效

此前，迁移旧 EFI 中相关的 `DeviceProperties`
配置后，音频恢复正常。遇到相同问题时，应优先对照该已知可用配置。不要不加区分地覆盖整个新配置；应比较相关键值并保留备份。

### 蓝牙无法使用

确认 USB 蓝牙设备是否被识别，记录其
VID:PID（`0489:E122`），并收集脱敏日志。只有在配对、连接和重新连接等环节完成测试后，才能宣称问题已解决。

### 亮度控制无效

记录屏幕与平台的实际表现、可用亮度控制方式以及相关日志。避免未经验证的
ACPI 修改，并保留可恢复的 EFI。

### 无法启动或配置异常

确认配置与 OpenCore
版本及目标设备相匹配，检查最近的修改、固件设置和脱敏日志。不要默认不同机型的配置可以互换。

## 其他 ASUS TUF AMD 机型的测试

本仓库当前的主要测试对象是 **ASUS TUF Gaming A16
FA608PM**。未来可能研究其他搭载 AMD 处理器的 ASUS TUF
笔记本，但每个型号都应被视为独立的测试对象。

不同 CPU
世代、显卡、无线网卡、蓝牙模块、音频设备、屏幕和固件可能需要不同的配置。一个型号的测试结果不能证明另一个型号也兼容。贡献测试结果时，请写明准确型号与实际测试的硬件。
